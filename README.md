# 💱 Currency Converter

A simple, responsive web application that converts real-time exchange rates between different global currencies using a live exchange rate API.

---

## 🚀 Features

* **Real-Time Exchange Rates:** Fetches up-to-date conversion rates via API.
* **Country Flag Integration:** Automatically displays the corresponding national flag when selecting a currency.
* **Responsive UI:** Clean, modern layout built for both mobile and desktop screens.
* **Bidirectional Conversion:** Quickly swap and calculate values across international currencies.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and form elements
* **CSS3:** Responsive layout, modern styling, and transitions
* **JavaScript (ES6+):** Fetch API integration and dynamic DOM manipulation
* **Flags API:** FlagCDN / FlagsAPI for visual currency icons
